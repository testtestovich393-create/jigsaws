Jigsaw Together
A jigsaw puzzle you solve together — in real time.

Press Play and share the invite link — everyone who opens it plays on the same board, no installs and no server needed. Or paste a table code above. The page can be hosted on any static host (GitHub Pages, Netlify, …) or opened as a plain file to play solo.

New game

Pick how many pieces go along the picture's shorter side — the other side, the piece count and the world size all follow from the picture's own shape, so pieces always stay square. Everyone connected follows automatically.

How it works

Playing

Drag pieces with the mouse or finger. Wheel / pinch zooms. With a mouse, the table pans only while the middle mouse button is held; on touch screens drag with one finger or pinch. A piece glows in a player's colour while they hold it — only one player can hold a group at a time. Pieces snap to each other when the fit is close, and to the frame when they reach their place.

Every player keeps a full copy of the board in this browser — close the tab any time and come back with Continue last session. When a table link is reopened after everyone left, the game offers to continue the local copy under the SAME link, so old invites keep working. Opened as a plain file (no web address), the page simply plays solo.

Playing together

Open a tablePress Play: the page claims a room code and the address gains #j=code. The Invite button (top bar) copies that link.
JoinOpen an invite link, type a nickname — that is all. A running game pulls you straight in; on an empty table the first player picks a picture and deals. Can't pass a link? Type the table code (the part after #j=) into the code box on the start screen and press Join.
The hostThe player who opened the table is its referee: their tab grants piece locks and relays the moves. If they close the tab, the next player takes over hosting automatically (a few seconds) and the table keeps its link.
Live movesWhile you drag, piece positions stream ~30 times per second and are interpolated, so pieces glide on other screens.
LocksA grabbed group is locked by the host: only one player can hold a group, a late grab is refused and the piece shakes. Locks expire after 30 s without motion and vanish on drop or disconnect.
PictureThe picture is chosen when a new game is created and travels between players as hash-checked chunks — late joiners fetch it automatically.

Put it online (GitHub Pages and friends)

The file is fully static — hosting it is a two-minute job:

GitHub PagesCreate a repository, upload this file as index.html, then Settings → Pages → deploy from the main branch. Your table link will look like https://name.github.io/repo/#j=code.
Netlify / Vercel / CloudflareDrag-and-drop the file onto their deploy page — done.
Own signallingAppend ?broker=host:port/path to the address to use a self-hosted PeerJS broker (e.g. npx peer --port 9000 --path /peerjs) instead of the public one — useful for closed networks or offline parties.

Network notes

Game data flows directly between the players' browsers (WebRTC). The only infrastructure is the tiny signalling broker used to find each other — the public PeerJS cloud by default, or your own via ?broker=. Browsers require a secure context for peer-to-peer: serve the page over HTTPS (GitHub Pages does this automatically) or from localhost. No accounts, no tracking, game data never touches a server.
